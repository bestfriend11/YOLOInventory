The following is a brief description of each sample application:

ANSI      Demonstrates the SmartHeap C ANSI API.

CPP       A C++ example application that uses SmartHeap operators
          new and delete, and defines overloaded new and delete
          operators for a linked list class definition.

LISTLIB   A DLL for linked list management, written in C.
          Thorough example demonstrating fixed-size memory
          pools.

LISTAPP   A complete application, written in C, that uses the
          services of the LISTLIB DLL above.  Demonstrates
          error detection and recovery, safety levels, garbage
          detection, and low-memory handling.

DEBUG     A simple demonstration of the Debug SmartHeap APIs.

SHAREMEM  Samples illustrating SmartHeap shared memory APIs.

Each sample includes project files for Visual C++ 6 users and a mak file 
generated with VC++ 4.2
