DSAnimViewer Keyboard Bindings

 

'-'         -- slow down animation rate

'+'         -- increase animation rate

'backspace' -- reset animation rate

'spacebar'  -- pause animation

 

'M'         -- load a different mesh

'A'         -- load a different animation

 

'F'         -- toggle floor render

ctrl-'F'    -- load floor texture

alt-'F'     -- cycle floor texture scale factor

 

'D'         -- toggle default pose

'J'         -- toggle jog in a circle (for run/walk/crawl animations)

'R'         -- toggle display of root position marker under character

 

'X'         -- toggle camera follows target

'G'         -- reset camera position to game view

 

'L'         -- toggle wireframe render

'N'         -- toggle display of vertex normals

'B'         -- toggle display of bones

 

'T'         -- toggle texture render

'U'         -- update textures (reload any texture surface descriptions)

 

'\'         -- toggle display of light ray

'O'         -- toggle light ray orbiting main mesh

'Z'         -- toggle lighting test mode (camera orbits untextured object)

 

left/right  -- rotate camera

up/down     -- zoom camera
