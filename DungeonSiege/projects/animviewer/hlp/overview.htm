The DSAnimViewer

 

What does it do?

 

n     Allows artists to verify that content exported by Siege Max will render as expected in the game.

n     Allows you to view exported ASP & PRS files directly, without having to create templates.

 

What doesn’t it do?

 

n     Currently has no way to browse for content located inside of tanks.

n     Does no checking for valid mesh/animation/texture combinations (by design).

n     Does not load SNO (terrain) files.
