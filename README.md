# YOLO Inventory Suite Scaffolding

This folder contains scaffolded plugins for the modular YOLO inventory suite:

- YOLOInventoryCore
- YOLOInventorySchema
- YOLOInventoryGrid
- YOLOInventoryEquipment
- YOLOInventoryLoot
- YOLOInventoryUI
- YOLOInventoryGASBridge
- YOLOInventoryEditorCore
- YOLOInventoryEditorSchema
- YOLOInventoryEditorGrid
- YOLOInventoryEditorLoot
- YOLOInventoryLegacyBridge
- YOLOInventoryTemplateDS1

All plugins are created as `EnabledByDefault=false` to keep current project behavior unchanged.
No runtime/editor code has been moved yet.
